Deep Learning Internship Notes: Core Architectures

Autoencoders and Denoising Autoencoders
An autoencoder is a neural network trained to reconstruct its own input. It consists of an encoder, which compresses the input into a smaller latent representation, and a decoder, which reconstructs the original input from that representation. A denoising autoencoder is a variant that is trained on corrupted (noisy) input images, but the target output remains the clean original image. This forces the network to learn robust features that capture the true underlying structure of the data rather than memorizing noise. Denoising autoencoders are commonly evaluated using Mean Squared Error (MSE), which measures the average squared difference between reconstructed and original pixels, and Peak Signal-to-Noise Ratio (PSNR), which measures reconstruction quality in decibels, with higher values indicating better reconstruction.

Convolutional Neural Networks versus Artificial Neural Networks
An Artificial Neural Network (ANN) is composed of fully connected layers where every neuron connects to every neuron in the next layer. ANNs do not inherently understand spatial relationships in images, so when applied to image data they typically require the image to be flattened into a one-dimensional vector, discarding spatial structure. A Convolutional Neural Network (CNN) instead uses convolutional filters that slide across the image to detect local patterns such as edges, textures, and shapes, while preserving spatial relationships. CNNs generally outperform ANNs on image classification tasks such as CIFAR-10 because they require fewer parameters and generalize better to unseen images. Data augmentation, such as random rotations, flips, and shifts, can further improve a CNN's ability to generalize by artificially expanding the diversity of the training set.

Recurrent Neural Networks: Vanilla RNN, LSTM, and GRU
A Recurrent Neural Network (RNN) processes sequential data by maintaining a hidden state that is updated at each time step, allowing information from previous steps to influence future predictions. Vanilla RNNs suffer from the vanishing gradient problem, which makes it difficult for them to learn long-range dependencies in long sequences. Long Short-Term Memory (LSTM) networks address this problem by introducing gating mechanisms, specifically input, forget, and output gates, along with a cell state that can carry information across many time steps with minimal decay. Gated Recurrent Units (GRU) are a simplified alternative to LSTM that combine the forget and input gates into a single update gate and merge the cell state and hidden state, resulting in fewer parameters while achieving comparable performance on many text generation tasks.

Retrieval-Augmented Generation (RAG)
Retrieval-Augmented Generation is a technique that combines a retrieval system with a generative language model. Instead of relying purely on the parameters of a language model, a RAG system first retrieves relevant chunks of text from an external knowledge base using vector similarity search, and then provides those chunks as context to a language model so that it can generate an answer grounded in real data. This approach reduces hallucination and enables question answering over private or domain-specific documents that the language model was never trained on. The core pipeline consists of document ingestion, text chunking, embedding creation, vector storage, query embedding, context retrieval, and finally answer generation.

Training Configuration Notes
Across the internship's weekly projects, models were typically trained using the Adam optimizer, with categorical cross-entropy loss used for classification tasks and mean squared error loss used for reconstruction tasks like autoencoders. Early stopping, which monitors validation loss and halts training when it stops improving, was introduced in later weeks to prevent overfitting and reduce unnecessary training time.
